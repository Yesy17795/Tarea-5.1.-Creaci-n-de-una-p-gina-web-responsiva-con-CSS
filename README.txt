Proyecto de Página Web Responsiva
Este proyecto consiste en la creación de una página web responsiva utilizando HTML5 y CSS.
La página incluye un menú de navegación, diferentes secciones de contenido y un diseño adaptable a distintos tamaños de pantalla.
Se utilizaron etiquetas semánticas de HTML5 y estilos CSS para organizar y personalizar el contenido de la página.
El objetivo es crear una página organizada, funcional y facil de visualizar tanto en computadoras como en dispositivos móviles.
